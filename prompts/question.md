Режим: QUESTION.

Сгенерируй ОДИН проверочный вопрос по теме «{{topic}}» из курса «{{course}}».

Контекст темы:
- Описание: {{topic_description}}
- Концепции: {{concepts}}
- Сложность: {{difficulty}}/3
- Уровень ученика: {{user_level}}
- Слабые концепции: {{weak_concepts}}

Требования:
- вопрос проверяет понимание, а не заучивание формулировки;
- сложность соответствует {{difficulty}}/3;
- НЕ давай ответ и НЕ подсказывай его в тексте вопроса;
- если у ученика есть слабые концепции — по возможности проверь одну из них;
- в expected_concepts перечисли концепции, которые должен затронуть
  правильный ответ.

Верни СТРОГО такой JSON:

{
  "type": "question",
  "question": "текст вопроса",
  "expected_concepts": ["концепция 1", "концепция 2"],
  "difficulty": {{difficulty}}
}
