# AI-преподаватель программирования (Telegram-бот)

Персональный Telegram-бот, который **учит**, а не выдаёт готовые ответы:
объясняет тему, задаёт вопросы, оценивает ответ структурно, отслеживает
`mastery` и не пускает дальше, пока тема не понята. Прогресс хранится в SQLite
и переживает перезапуск бота.

- Python 3.12+ / aiogram 3.x / SQLAlchemy 2.0 (async, aiosqlite)
- OpenRouter (OpenAI-compatible API) для объяснений, вопросов и проверки
- Long polling, без webhook/Docker/фронтенда

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env      # и заполни TELEGRAM_BOT_TOKEN и OPENROUTER_API_KEY
python bot.py
```

## Команды

| Команда | Действие |
|---|---|
| `/start` | регистрация, приветствие, меню |
| `/courses` | список курсов |
| `/learn` | продолжить обучение с текущей темы |
| `/progress` | прогресс по курсу |
| `/stats` | статистика обучения |
| `/exam` | экзамен по пройденным темам |
| `/stop` | остановить текущую сессию |
| `/help` | справка |
